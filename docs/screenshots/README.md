# Screenshots

Put the demo recording here as `demo.gif`, then uncomment the image line at the top of
`README.md`.

Recording it in a terminal:

```bash
asciinema rec demo.cast   # run: blindagem audit, then blindagem explain ssh.root_login
agg demo.cast demo.gif    # https://github.com/asciinema/agg
```

Worth capturing, in this order: the score panel, one finding with its evidence, an
`explain`, and the generated playbook. Keep it under 30 seconds.
